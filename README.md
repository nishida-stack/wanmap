# わんカフェわんランマップ

大阪・兵庫・京都・奈良の、看板犬のいるドッグカフェ・ドッグランの地図です。目印をタップすると看板犬の写真・動画がすぐ見られます。

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリの画面 |
| `data.js` | お店のデータ（下の手順で自動作成） |
| `tools/kanban/*.json` | 看板犬のいるお店の調査結果（地域ごと）。看板犬の名前・犬種、出典、埋め込む投稿 |
| `tools/build_kanban.py` | 上の調査結果から `data.js` を作成（位置の検索、投稿・動画が今も見られるかの確認） |
| `tools/fetch_osm.py` ほか | 旧版（全国379か所の地図）で使っていたもの。現在は使っていません |

## データの更新

お店を追加・修正するときは `tools/kanban/` の該当ファイルを直し、次を実行します。

```
cd tools
..\..\.venv\Scripts\python.exe build_kanban.py
```

見られなくなった投稿・動画は自動で外れ、結果に表示されます。京都の通り名入りの住所など、位置がずれるお店は `"geo"` に町名までの住所を入れます。

## 費用

すべて無料のサービスのみ使用（国土地理院の地図・住所検索、Instagram/YouTube/X の公式埋め込み、GitHub Pages）。

## 注意

- 看板犬やお店の情報は調査時点（2026年9月）のもの。
- YouTube の埋め込みは、ファイルをダブルクリックで開いた状態では再生されません。公開先のページで確認してください。
